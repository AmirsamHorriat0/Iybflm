Two reasons:
1. My laptop battery was sketchy
2. I wanted to learn Rust

### Rust required
``` bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```
# Installation

``` bash
git clone https://github.com/AmirsamHorriat0/Iybflm.git
cd Iybflm
cargo build && cargo run
```
## Or 
``` bash
wget https://github.com/AmirsamHorriat0/Iybflm/releases/download/v0.1.0/power-manager -O iybflm
chmod +x iybflm
sudo mv iybflm /usr/local/bin/
sudo iybflm
